# Open Seas

Minecraft 1.21.1 mod for Fabric and NeoForge. Turns the overworld into open ocean dotted with islands and
archipelagos of every size, from sea stacks to landmasses a few thousand blocks across. Terrain and biomes on the
islands are vanilla's (or whatever biome mods you run), so it stays compatible with them.
